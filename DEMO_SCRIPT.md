# Demo Script: PharmaQMS

This guide allows an evaluator to complete the demonstration quickly and verify all major functionalities of the application.

## 1. Start Application
Ensure your PostgreSQL database is running.
Start the backend:
```bash
cd backend
uvicorn app.main:app --reload
```
Start the frontend:
```bash
cd frontend
npm run dev
```

## 2. Open New Complaint
Navigate to the **Dashboard** at `http://localhost:5173/dashboard` and click **Log New Complaint**.

## 3. Enter Natural-Language Complaint
In the AI Co-Pilot chat on the right, type:
> *"A customer reported discolored capsules for Neurovit 500 mg, batch NV24081. 20 bottles are affected."*

## 4. Show Log Complaint Tool
The AI Co-Pilot interprets the intent, selects the `log_complaint` tool, and executes.

## 5. Show Automatic Form Population
Notice the form on the left instantly populates with:
- **Product:** Neurovit
- **Strength:** 500 mg
- **Batch:** NV24081
- **Quantity:** 20 bottles
Pulsing badges appear next to fields modified by the AI.

## 6. Show Risk Assessment
An **AI Result Card** appears in the chat showing the severity, priority, and recommended actions automatically generated by the LLM.

## 7. Edit Complaint Using Natural Language
In the AI Co-Pilot chat, type:
> *"Correction: batch number is NV24082 and quantity is 35 bottles."*

## 8. Show Only Requested Fields Changed
The `edit_complaint` tool executes. Notice that ONLY the Batch and Quantity fields change on the form. The Product, Strength, and Complaint details remain fully intact.

## 9. Upload Complaint PDF
Click the **Upload supporting document** button in the Co-Pilot panel. 
Select `demo_data/sample_batch_quality_complaint.pdf`.

## 10. Show Document Extraction Tool
The AI invokes the `extract_complaint_document` tool. The UI shows progress ("Reading document...").

## 11. Show Automatic Form Population
The document information is extracted and merged. Missing fields like Customer Name are populated without overwriting existing correct data.

## 12. Edit Extracted Complaint Using Natural Language
In the Co-Pilot, type:
> *"The affected quantity should be 42 bottles."*
Observe the AI cleanly patching just the quantity to 42.

## 13. Save Complaint
Click the blue **Save Complaint** button at the bottom of the form. Wait for the success notification.

## 14. Open Saved Complaint
Navigate to the **Complaints List** and click on the newly created complaint to reopen it.

## 15. Show Audit History
Scroll down to the bottom of the form. The **Audit Trail** component will load, showing every single change the AI made, including the exact previous and new values (e.g., Batch NV24081 -> NV24082), verifying full PostgreSQL persistence.
